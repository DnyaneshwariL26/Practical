def greet(bot_name, birth_year):
    print("Hello! My name is {0}.".format(bot_name))
    print("I was created in {0}.".format(birth_year))
def remind_name():
    print('Please, remind me your name.')
    name = input()
    print("What a great name you have, {0}!".format(name))
def guess_age():
    print('Let me guess your age.')
    print('Enter remainders of dividing your age by 3, 5 and 7.')
    rem3 = int(input())
    rem5 = int(input())
    rem7 = int(input())
    age = (rem3 * 70 + rem5 * 21 + rem7 * 15) % 105
    print("Your age is {0}; that's a good time to start programming!".format(age))
def count():
    print('Now I will prove to you that I can count to any number you want.')
    num = int(input())
    counter = 0
    while counter <= num:
       print("{0} !".format(counter))
       counter += 1
def test():
    print("Let's test your programming knowledge.")

    print("2. To decompose a program into several small subroutines.")
    print("3. To determine the execution time of a program.")

    answer = 2
    guess = int(input())
    while guess != answer:
       print("Please, try again.")
       guess = int(input())

-------------------------theory-------------------

This chatbot is a console-based interactive bot designed to:
•	Greet the user and introduce itself.
•	Ask the user for their name and engage in a conversation.
•	Perform a mathematical trick to guess the user's age.
•	Demonstrate basic counting functionality.
•	Conduct a programming knowledge quiz.
•	End the interaction with a farewell message.
The chatbot operates sequentially using functions, which makes it a structured approach for user interaction.
Algorithm for TE-Chatbot
1.	Greet Function (greet(bot_name, birth_year))
o	Displays bot name and creation year.
2.	Remind Name Function (remind_name())
o	Asks for user name and responds with a personalized message.
3.	Age Guessing Function (guess_age())
o	Takes remainders when user's age is divided by 3, 5, and 7.
o	Applies modular arithmetic to calculate the actual age.
4.	Counting Function (count())
o	Asks the user for a number.
o	Counts from 0 to the given number using a loop.
5.	Programming Knowledge Quiz (test())
o	Asks a multiple-choice question about methods in programming.
o	Implements a while-loop for user retries.
6.	End Function (end())
o	Displays a final farewell message.
Data Structures Used (DSA)
1.	Variables → Used to store user inputs (name, age, guess).
2.	Lists (optional enhancement) → If we expand the bot, responses can be stored in lists.
3.	Loops (while, for) → Used in the counting and quiz functions.
4.	Functions → Encapsulates tasks in modular units for structured programming.
